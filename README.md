# COVID-19 Monthly and Cumulative Data (March 2020 - February 2021)

## Data Source & Availability
This dataset contains the monthly and cumulative COVID-19 statistics for Bangladesh, covering the period from March 2020 to February 2021. 

The data used in this research was aggregated from the following official and publicly accessible sources:
1. **Bangladesh Official COVID-19 Dashboard:** [DGHS Bed Status Display Graph](https://dghs.gov.bd)

## Status & Data Integrity Notice
* **Active Outage:** Please note that the official Bangladesh government dashboard link (`dashboard.dghs.gov.bd`) is currently offline and returns a **`502 Bad Gateway (nginx)`** error. 
* **Official Update:** The relevant authority has informed us that they are actively working to resolve these technical difficulties, and the live dashboard is expected to be fully functional again very soon.
* **Archival Purpose:** Due to the current live site availability issues, this repository serves as a permanent static archive of the corrected, verified data for this specific timeframe to ensure its long-term accessibility for academic research and data analysis.
